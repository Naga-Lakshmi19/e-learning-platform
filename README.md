# e-learning-platform

1. Developed a full-stack E-Learning Website as part of the internship project.
2. Designed the application to provide a simple, user-friendly, and interactive online learning environment.
3. Implemented different learning modules such as subjects, lessons, bookmarks, learning history, and chatbot support.
4. Developed user authentication features including registration and login.
5. Implemented separate User and Admin modules for better management and access control.
6. Created web pages including:
  Home Page
  Login Page
  Signup Page
  Subject Pages
  Lesson Pages
  Bookmarks Page
  Chatbot Page
  Contact Page
  Admin Pages
7. Used HTML to create and organize the structure of different web pages.
8. Used CSS to design an attractive, responsive, and user-friendly interface.
9. Used JavaScript to provide interactive functionality and improve the user experience.
10. Implemented database connectivity to store and manage application data.
11. Stored information related to users, subjects, lessons, bookmarks, chatbot content, contact messages, and learning history.
12. Used Visual Studio Code as the primary development environment.
13. Used Google Chrome for running, testing, and debugging the application.
14. Used Chrome Developer Tools to inspect elements, debug errors, and test webpage responsiveness.
15. Used GitHub for source-code management, version control, and maintaining project backups.
16. Used a local development environment to develop and test the application before deployment.
17. Improved practical knowledge of frontend and backend development.
18. Gained experience in database management and data handling.
19. Improved problem-solving, debugging, and testing skills through project development.
20. Gained practical understanding of the software development workflow.
21. Improved skills in project documentation and maintenance.
22. Gained hands-on experience in developing an industry-oriented web application.
23. Enhanced confidence in working with real-world full-stack development projects.
